# Desktop Avatar — фотореалистичный компаньон для macOS

Прозрачный оверлей поверх рабочего стола: фотореалистичный персонаж (MetaHuman),
который живёт своей жизнью, реагирует на события Personal OS и отвечает **текстом**
в пузыре. Без голоса.

> **Этическая рамка (жёсткая).** Лицо персонажа — **оригинальная** композиция,
> узнаваемо отличная от любого реального человека. Берём только общий типаж
> (тёмные волосы, латиноамериканские черты, тепло/харизма). Мы **не**
> воспроизводим likeness реального человека. Это не обсуждается.

## Как это устроено (Этап 1, MVP)

Фотореализм **без** запущенного игрового движка в рантайме:

```
MetaHuman Creator ──► UE5 сцена+свет ──► рендер клипов с АЛЬФА-каналом
   (ручной труд)         (ручной труд)       (idle, моргание, эмоции)
                                                      │
                                                      ▼
                                       Resources/clips/*.mov (ProRes 4444 alpha)
                                                      │
   ┌──────────────────────────────────────────────── ▼ ─────────────────┐
   │  Swift/AppKit приложение-оверлей (этот репозиторий)                 │
   │                                                                     │
   │  OverlayWindow ── прозрачное borderless-окно, все Spaces, .floating │
   │  AvatarView    ── AVPlayer проигрывает alpha-клипы (Metal-слой)     │
   │  StateController ─ конечный автомат: idle ⇄ эмоции                  │
   │  SpeechBubble  ── текстовые реплики                                 │
   │  PosEventListener ─ поллит mission-control 127.0.0.1:8787           │
   │  CharacterConfig ─ пресеты характера + маппинг событие→реакция      │
   └─────────────────────────────────────────────────────────────────────┘
```

Событие pos (`/api/state`, `/api/hh`, …) → правило в конфиге → смена состояния →
проигрывается клип + опционально показывается текст.

## Что делается ВРУЧНУЮ (вне этой среды)

Эти шаги нельзя сделать кодом здесь — их выполняет пользователь:

1. **MetaHuman Creator** — собрать **оригинальное** лицо персонажа (типаж задан,
   но лицо уникальное, не копия реального человека).
2. **UE5** — импортировать MetaHuman, поставить сцену, свет, камеру.
3. **Рендер клипов** с альфа-каналом (Movie Render Queue → ProRes 4444):
   - `idle_breathe.mov` — спокойное дыхание, петля 4–8 c
   - `blink.mov` — моргание, 0.3 c (или встроить в idle-вариации)
   - `happy.mov`, `wave.mov`, `think.mov`, `surprise.mov` — эмоции-реакции
4. Положить готовые `.mov` в `Resources/clips/` под именами из конфига.

## Что собрано КОДОМ здесь

- Прозрачное окно-оверлей, воспроизведение alpha-видео, drag мышью.
- Конечный автомат состояний, менеджер текстовых пузырей.
- Слушатель событий pos (поллинг mission-control).
- Схема и загрузчик конфига характера + 3 пресета.
- Заглушки клипов и инструкция по их запеканию.

## Запуск (после того как появятся клипы)

```bash
cd apps/desktop-avatar
swift run DesktopAvatar
```

Пока клипов нет — приложение стартует с плейсхолдером (силуэт), чтобы можно было
проверить окно, drag, пузыри и реакции на события.

Конфиг характера: `Resources/characters/*.json`. Активный пресет —
переменная окружения `AVATAR_CHARACTER` (по умолчанию `warm-playful`):

```bash
AVATAR_CHARACTER=bold swift run DesktopAvatar
```

У каждого характера **свой набор клипов** в `Resources/clips/{preset}/` —
мимика и жесты отличаются от пресета к пресету (см. `Resources/clips/README.md`).

### Облик (внешность) — переключается в меню-баре → «Облик»

Характер = личность/цвет/реплики. **Облик** = как персонаж выглядит, отдельно:

| id | Что это |
|----|---------|
| `holo` | **Пиксельная девушка-голограмма (стиль JOI, Blade Runner 2049)** — во весь рост, синяя, на проекторной подставке. Рисуется процедурно на canvas внутри прозрачного `WKWebView` (`HologramView` + `Resources/avatar.html`): портрет 100×230 → nearest-neighbor апскейл, chromatic split, bloom, CRT-сканлайны, scan-sweep, flicker, глитч, конус света + пыль, idle-float + моргание. Выражения idle/happy/curious дёргает `AvatarStateController` (эмоции клипов маппятся в выражения), клипы `.mov` не нужны. **Дефолтный облик.** |
| `blob` | Желейная капля, нарисована кодом (`CreatureView`), с пружинной физикой |
| `pet` | Дух-котик, нарисован кодом (`CreatureView`): ушки, глаза, носик, усы, хвост |
| `lottie:{name}` | Готовая скачанная **Lottie**-анимация (векторная, с альфой) из `Resources/lottie/{name}.json`, рендерится через Airbnb Lottie |

Встроены: `lottie:cactus` (смеющийся кактус), `lottie:wave` (человечек машет).
Облик меняется на лету, **запоминается** в `~/Library/Application Support/DesktopAvatar/settings.json`
и **пишется в лог действий** (Obsidian → memory-extractor), как и смена характера.
Стартовый облик можно задать окружением:

```bash
AVATAR_APPEARANCE=lottie:wave swift run DesktopAvatar
```

**Добавить свою анимацию:** положи любой bodymovin/Lottie JSON (лучше без solid-фона
и без растровых image-слоёв — тогда фон прозрачный) в `Resources/lottie/`, затем
добавь пару `("lottie:имя_файла", "Название")` в список `appearances` в `AppDelegate.swift`.
Хорошие бесплатные анимации — на lottiefiles.com (скачивать «Lottie JSON»).

## Голос через Siri (Shortcuts)

Аватар поднимает мини-HTTP на `127.0.0.1:8788` (только loopback, порт настраивается
через `AVATAR_SIRI_PORT`). Siri здесь — микрофон и динамик; думает аватар:

```
«Привет Siri, спроси Джои» → шорткат диктует фразу → POST /ask → ChatBrain/AgentBrain
     → ответ показывается в пузыре + возвращается шорткату → «Озвучить текст»
```

- `GET /ask?text=привет` или `POST /ask` с JSON `{"text":"привет"}` → `{"reply":"…"}`
- Обычная реплика — ждём ответ мозга (Opus, ~10–20 с) и озвучиваем его.
- Системная задача («сделай…», «проверь…», `!…`) — уходит в AgentBrain, а шорткату
  сразу возвращается «Приняла, работаю» (иначе Shortcuts отвалится по таймауту);
  результат появится в пузыре.
- Если аватар ещё думает над прошлым вопросом — вернёт «спроси чуть позже».

Как собрать шорткат — см. раздел «Запуск» ниже и инструкцию в корневом отчёте.
