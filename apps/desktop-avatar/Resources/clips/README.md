# clips/ — фотореал-клипы с альфа-каналом, СВОИ под каждый характер

Рендерятся **вручную в UE5**, в репозиторий не коммитятся (см. `.gitignore`).
Пока их нет — приложение показывает плейсхолдер-силуэт.

## Структура: свой набор под каждый пресет характера

```
clips/
  warm-playful/   ← тёплая и игривая: живая мимика, широкие жесты
  calm-elegant/   ← спокойная: сдержанная мимика, плавные движения
  bold/           ← дерзкая: резче, с характером
```

Приложение берёт клипы из `clips/{AVATAR_CHARACTER}/`. Имена файлов внутри
каждой папки — **одинаковые** (меняется исполнение, не имена):

| Файл | Что | Длина | Петля |
|------|-----|-------|-------|
| `idle_breathe.mov` | спокойное дыхание, микродвижения | 4–8 c | да |
| `blink.mov` | моргание / лёгкая idle-вариация | ~0.5 c | нет |
| `happy.mov` | улыбка / радость | 1–2 c | нет |
| `wave.mov` | приветственный жест | 1–2 c | нет |
| `think.mov` | задумчивость / лёгкая тревога | 1–2 c | нет |
| `surprise.mov` | удивление | 1–2 c | нет |

Итого: 6 клипов × 3 характера = **18 рендеров**. Если объём великоват — можно
начать с одного пресета (`warm-playful`), остальные добавить позже.

## Как запечь из UE5 (Movie Render Queue)

1. Оригинальный MetaHuman в сцене на **прозрачном фоне** (нет skybox; в Movie
   Render Queue включить сохранение альфы).
2. Output: **Apple ProRes 4444** (`.mov`) — надёжно несёт альфа-канал,
   AVFoundation читает «из коробки». (HEVC-alpha — поздняя оптимизация.)
3. **Калибровка (обязательно):** сначала отрендерь ОДИН эталонный клип и проверь
   в приложении, что нет тёмной/светлой каймы (halo) вокруг фигуры — это
   premultiplied alpha. Только убедившись — рендерь остальные.
4. Разрешение под окно (портрет), напр. 640×960 или 720×1080.
5. Разложить по папкам пресетов под именами из таблицы.

> Проверка прозрачности: клип должен показываться без прямоугольника вокруг
> фигуры. Есть фон — альфа не сохранилась при рендере.
