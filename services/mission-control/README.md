# Mission Control — пульт Personal OS

Локальный веб-дашборд всей системы: **http://127.0.0.1:8787** (только localhost).
Продуктовый SPA со светлой темой, боковой навигацией, без зависимостей (Python stdlib),
автообновление активного экрана каждые 5 с.

## Экраны
- **Обзор** — сводные карточки (сервисы, задачи, ошибки крона, hh, блог), таблица крон-задач
  с управлением и лента запусков.
- **Страница сервиса** (по каждому: cron, claude-local-api, tg-blog-editor, tg-psych-bot,
  mission-control) — статус/pid/аптайм/перезапуски + **детальная аналитика под конкретный сервис**:
  - `cron` — задачи, успехов/ошибок запусков, radar (инфополе), лента;
  - `claude-local-api` — **активность через сокет**: вызовы других процессов (промпт→ответ, модель, время), разбивка по моделям;
  - `tg-blog-editor` — черновики/публикации/пропуски, прогон дайджеста;
  - `tg-psych-bot` — чек-ины, очередь outbox, сообщения канала, расписания;
  - `mission-control` — Claude-сессии, аптайм;
  - у каждого — раскрываемый лог сервиса.
- **Хранилище контекстов** — разделитель на две вкладки:
  - **Графы памяти** — граф связей (Obsidian L4) + библиотека Zotero;
  - **Изображения** — визуальные референсы (борды-мудборды как Pinterest). Борды с полярностью
    **✅ Нравится** (do's) / **⛔ Не нравится** (don'ts); добавление ссылками, публичным
    бордом/пином Pinterest (пачкой) или загрузкой файлов; кнопка «визуальное ДНК» отдаёт
    борд в Claude-роут на анализ. Данные — в Obsidian `08 — Шаблоны и ресурсы/Визуальные
    референсы/`, движок — `tools/context-store/store.py`.
- **Claude Code** — агент в каталоге проекта (см. ниже).

## Боковая навигация
Слева — статус-точки каждого сервиса (🟢/🔴) в реальном времени, внизу — состояние супервизора и часы.

## Кнопки (реально управляют системой)
| Кнопка | Действие | Под капотом |
|--------|----------|-------------|
| `▶ run` | запустить задачу сейчас | `cronctl.py run <id>` (в фоне) |
| `on/off` | включить/выключить задачу | `cronctl.py enable/disable <id>` |
| `log` | хвост лога задачи | фильтр `cron/logs/cron.log` |
| `↻ restart` | перезапуск супервизора | `pos.py restart` |

## Запуск
Под супервизором — автоматически (сервис `mission-control` в `services.json`).
Вручную: `python3 server.py` (порт меняется через `PORT=9000`).

## Claude Code из-под UI (вкладка «Claude Code»)
Чат с Claude Code прямо в дашборде: запускается `claude -p` со стримингом (`stream-json`)
в каталоге проекта, с инструментами и продолжением диалога.

- **Стрим** — ответ и вызовы инструментов (Bash/Edit/Read…) появляются вживую.
- **Мои сессии** — каждый диалог хранится (`claude_sessions.json`), слева список; клик — **подгружает
  историю сообщений** из `~/.claude/projects/…/<id>.jsonl` и продолжает через `--resume`. `+ новая` — с нуля.
- **Через local-API** (вторая вкладка слева) — лента сессий, которые запускают **другие процессы**
  (крон, боты) через сокет `/tmp/claude_api.sock`: промпт, ответ, модель, время. Источник —
  `services/logs/localapi-activity.jsonl` (пишет `claude-local-api`).
- **Модель** — Sonnet / Opus / Haiku (селектор).
- **Уровень прав** (селектор):
  | Режим | Флаг claude | Что можно |
  |-------|-------------|-----------|
  | 🛡 Plan | `--permission-mode plan` | только чтение/исследование, без правок (по умолчанию) |
  | ✏️ Авто-правки | `--permission-mode acceptEdits` | автоприменение правок файлов |
  | ⚡ Полный доступ | `--dangerously-skip-permissions` | любые инструменты без подтверждений |

Эндпоинты: `POST /api/claude/send` (NDJSON-стрим), `GET /api/claude/sessions`.
Рабочий каталог по умолчанию — корень проекта `personal os`.

> ⚠️ Plan-режим read-only; для реальных задач (правки кода, запуск) выбирай Авто-правки или
> Полный доступ. Полный доступ = автономный агент без спросов — применяй осознанно.

## Безопасность
Сервер слушает только `127.0.0.1`. Управляющие ручки доступны лишь с этой машины.
Claude Code наследует авторизацию Claude Code этой машины — ключи в коде не нужны.
