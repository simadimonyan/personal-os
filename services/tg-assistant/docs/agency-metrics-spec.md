# Спека: метрики авторства / софт-скиллов (агентность)

Источник: план психокоманды `10 — Claude/Рабочее пространство/psych/metrics_plan.md` (2026-07-26).
Цель — мерить **действия** («сделал / не сделал»), а не оценивать личность. Ядро: **«решил сам · было страшно · сделал»**.

Ключевой архитектурный принцип: **дневник состояний (morning/day/evening/situational) меряет СОСТОЯНИЕ; новые слоты меряют АГЕНТНОСТЬ.** Они пишутся отдельными секциями и НЕ сводятся в общий балл. Никаких сумм, стриков, вердиктов, итоговой строки. Пропуск = 0, не −1.

## Что добавляем

### 1. Ежедневно — слот `agency` («🧭 Развилка»)
Отдельный чек-ин (своя строка `checkins`, своя секция `## 🧭 Развилка · HH:MM`). Запуск:
- кнопка меню «🧭 Развилка»;
- инлайн-кнопка в конце вечернего чек-ина (едет на вечернем пинге, без отдельного нытья).

Поток:
1. **Развилка** (enum `agency_fork`): решил сам / подчинился / поспорил-назло / развилки не было.
   - «развилки не было» — честный ответ, не провал; поток сразу к базе.
2. **Кому** (enum `agency_addressee`, только если развилка была): близкие / друзья / дело / сам с собой / ✏️ своё. Роли обобщённые — без конкретных имён; частности можно вписать через «✏️ своё».
3. **Что именно** (free text, опц., только если развилка была) → пишется цитатой в секцию.
4. **База / Фаза 0** (multi `base_done`): сон / тело / ходьба — тумблеры, отсутствие = нет.
5. Мягкое закрытие (без вопроса, без оценки).

Встроенный тест авторства показывается строкой-подсказкой у вопроса «Развилка», не отдельным полем: «Выбрал бы то же, если бы ключевой человек сказал да / если бы никто не узнал?».

### 2. По событию — слот `deed` («📌 Поступок»)
Только когда случилось (никаких напоминаний). Кнопка меню «📌 Поступок» / `/deed`.
- **A. Столкнулся / накрыло → что сделал** (`deed_kind=A`): исход `deed_action` = вышел/сказал по делу/написал (выход) · проглотил из страха · сорвался; + кому; + опц. текст.
- **B. Сказал тяжёлое / попросил** (`deed_kind=B`): кому — тому, кто поддержит / тому, кто оценивает; + опц. текст.
- **C. Начал контакт первым** (`deed_kind=C`): + опц. текст (кому). Пустая неделя = «повода не было», не провал.

Пишется секцией `## 📌 Поступок · HH:MM`.

### 3. Раз в неделю — «Обзор недели» (3 вопроса)
Тик планировщика: воскресенье, позднее окно, один раз в ISO-неделю (guard в settings `weekly_review_done=YYYY-WW`). Устойчив к сну ноутбука (тик, не cron).
- **Н1. Где действовал:** только там, где решаю один / и с живыми людьми тоже + пример.
- **Н2. Спорил по делу, а не защищал себя:** да / нет + где.
- **Н3. Кому нёс важное:** тому, кто поддержит / тому, кто оценивает / не было + кому.
Пишется в rolling-файл `02 — Внутренний мир/Обзоры авторства/Недельные обзоры.md`.

### 4. Раз в месяц — «Обзор месяца» (7 фактов да/нет)
Тик планировщика: 1-е число, один раз в месяц (guard `monthly_review_done=YYYY-MM`). Один экран тумблеров (отмечено = да, снято = нет). Факты **обобщённые** — про действия, а не про конкретные проекты/людей (чтобы шаблон не устаревал вместе с целями):
1. Границу/«нет» сказал близким (`boundary`).
2. В споре держал позицию по делу, а не защищал себя (`position`).
3. Реальный шаг к своей большой цели (`goal`).
4. Сделал что-то для себя + тест «сделал бы, даже если никто не узнает» (`for_self`).
5. Попросил о помощи ИЛИ сказал тяжёлое тому, кто поддержит (`ask`).
6. Первым начал контакт — разговор, знакомство (`initiative`).
7. База — большинство дней месяца была (`base`).
Пишется в `02 — Внутренний мир/Обзоры авторства/Месячные обзоры.md`. Без суммы, без итога.

## Жёсткие правила (в коде)
- Новые слоты НЕ входят в `_STATE_SLOTS` heatmap → не создают стрик-давления.
- Нет числовых баллов у агентных метрик (только enum-факты и да/нет).
- Развилка «не было» и пустые события — не провалы, отдельного порицания нет.
- Тексты — короткие, простые, без метафор. Роли/факты обобщённые, без привязки к конкретным именам и проектам.
- Полное простое объяснение блока авторства — команда `/author` (+ строка в `/help`).
- Разговор с мамой наедине про крик — не предлагать.

- `obsidian/frontmatter.py` — `base_done` в list-merge.

- `states/checkin_states.py` — Agency/Deed/Weekly/Monthly states.
- `keyboards/agency.py` — клавиатуры.
- `handlers/agency.py`, `handlers/deed.py`, `handlers/review.py` — потоки.
- `keyboards/menu.py`, `handlers/commands.py`, `bot.py` — кнопки/роутеры/команды.
- `obsidian/writer.py`, `obsidian/paths.py`, `config.py` — rolling review-файлы.
- `scheduler/jobs.py` — недельный/месячный тик с guard.
- `handlers/today.py` — показ развилки/базы/поступков в «Сегодня».
