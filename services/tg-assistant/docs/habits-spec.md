# Спека: привычки (хорошие и вредные)

Настраиваемые привычки, которые Димитри заводит сам. Философия та же, что у
остального бота: **без стриков, без баллов, пропуск ≠ провал**. Счётчики и
динамика — **только в 📈 Аналитике**, в ежедневном виде их нет.

## Модель данных
- **Определения** — JSON-список в `settings['habits']`: `[{id, name, kind}]`, `kind ∈ {good, bad}`. CRUD — `app/domain/habits.py`.
- **Ежедневный трекинг** — слот чек-ина `habits` (`checkins.slot='habits'`). В `answers`: `habits_done` (хорошие — что **сделал**) и `habits_slip` (вредные — что **было / сорвался**) — списки имён. Пишутся во frontmatter как есть + секция `## 🌱 Привычки · HH:MM`.
- Слот `habits` **не** входит в `_PLAN_SLOTS`/heatmap → не создаёт стрик-давления.

## Поток (всё на кнопках)
- Кнопка «🌱 Привычки» / `/habits` → **хаб**: список привычек + кнопки «✅ Отметить за день», «➕ Добавить», «🗑 Убрать».
- **Добавить**: «➕ Добавить» → выбор типа кнопкой (🌱 Хорошая / 🚫 Вредная) → название одним сообщением (state `HabitsStates.adding`) → сохранено.
- **Убрать**: «🗑 Убрать» → список привычек кнопками, тап 🗑 → удалено (перерисовка).
- **Отметить**: «✅ Отметить за день» → экран тумблеров: хорошую — если **сделал**; вредную — если **сорвался** (было). Что не отмечено — просто не было.
- Callback-неймспейс `hb:*` (hub/add/addkind/del/delone/mark); тумблеры — `HabitCB` (prefix `habit`). Финализация трекинга — штатный `finalize_checkin` (outbox → Obsidian).
- Текстовые `/habit_add`, `/habit_del` оставлены запасным путём; `/habit_list` открывает хаб.

## Встраивание в стандартный день
- В конце **вечернего** чек-ина (слот с напоминалкой) едет опциональная кнопка «🌱 Привычки» → сразу экран отметки (`hb:mark`). Показывается, только если привычки заведены и сегодня ещё не отмечены. Тем же паттерном, что «🧭 Развилка дня» — на вечернем пинге, без отдельного нытья.

## Аналитика (`domain/stats.py`)
- Период (Σ за месяц): `habits_done` (сделал) / `habits_slip` (срывы) — число **ДНЕЙ** с отметкой по каждой привычке (дедуп по дате), `habit_days` — сколько дней вообще отмечал.
- День: `DayStats.habits_done/slip` — просто списки отмеченного, без счётчиков.
- «📊 Сегодня» и секция дневника — тоже без счётчиков (списки).

## Правила
- Никаких сумм/стриков/вердиктов в ежедневном виде. Счётчик — ретроспектива в аналитике, не давление.
- Список привычек — полностью пользовательский; код не зашивает конкретные привычки.
