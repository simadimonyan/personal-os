# Пикабу — разведка, участие и публикации

Работает под **личным аккаунтом через живую сессию Chrome**. Никаких приложений,
ключей и паролей в файлах — как у hh.ru и Reddit.

- `pikabu.py` — логика: разведка, гарды, вердикты, спеки, проверка постов (Python, stdlib)
- `driver.mjs` + `browser.mjs` — транспорт действий: системный Chrome через Playwright
- База `pikabu.db` · сессия `~/.pikabu-session/` · `config.json` — только гарды

**Чтение не требует ни входа, ни браузера.** Пикабу отдаёт страницы обычным
запросам, поэтому `find`, `comm`, `feed`, `search`, `story` работают мгновенно
через urllib. Chrome поднимается только под действия: `comment`, `post`, `me`.

## Чем Пикабу отличается от Reddit

На Reddit пост тихо снимает AutoModerator. Здесь автора убивает не модерация, а
**рейтинг**: пост формально жив, открывается по ссылке, но набрал −20 и его никто
не увидит. Второй способ исчезнуть — очередь модерации сообщества: пост открывается
по прямой ссылке и не появляется в ленте. `verify` различает три исхода: жив,
в минусе, снят — плюс отдельно «не видно в ленте сообщества».

Второе отличие — **ссылки**. У редактора есть отказ «Нельзя добавить пост со
ссылками вне блога», но срабатывает он не всегда: обычный пост с двумя ссылками
на опрос уходит без всякого флага (проверено 13.08.2026). Реальная цена ссылки —
не отказ, а минусы: это первое, за что здесь голосуют вниз. Преполёт про ссылки
предупреждает, а рекламный флаг `advert` требует юрлица.

Третье — **медленный режим**: свежим аккаунтам режут число комментариев в сутки.
`me` показывает, включён ли он.

## Настройка (один раз)

```bash
cd tools/pikabu
npm install                 # playwright; браузер не качается — берём системный Chrome
python3 pikabu.py login     # откроется Chrome, входишь руками, сессия сохранится
python3 pikabu.py me        # рейтинг, посты, ограничения новичка
```

## Порядок работы

```bash
cd tools/pikabu

# 1. разведка: где сидит аудитория и насколько ниша живая
python3 pikabu.py find "английский язык"
python3 pikabu.py comm info ligaenglish
python3 pikabu.py comm rules ligaenglish
python3 pikabu.py feed hot --community ligaenglish     # что тут заходит
python3 pikabu.py feed hot --tag "Английский язык"

# 2. преполёт по площадке (вердикт ложится в базу)
python3 pikabu.py comm check ligaenglish
python3 pikabu.py comm add ligaenglish --note "основная аудитория"
python3 pikabu.py comm list

# 3. участие — главный канал, риска ноль
python3 pikabu.py search "учу английский" --days 7 --min-comments 5
python3 pikabu.py story 14234819 --comments 15
python3 pikabu.py comment 14234819 --file ответ.md --dry
python3 pikabu.py comment 14234819 --file ответ.md --parent 401295600

# 4. публикация — из файла-спеки, после гардов
python3 pikabu.py post мой-пост.json --dry
python3 pikabu.py post мой-пост.json

# 5. ОБЯЗАТЕЛЬНО через час
python3 pikabu.py verify --all

# пост, опубликованный руками, — под наблюдение
python3 pikabu.py track 14240257

# состояние
python3 pikabu.py stats     # соотношение участия, судьба своих постов
python3 pikabu.py plan      # что гарды разрешают сегодня
```

## Спека поста

`post.example.json` + `post.example.md` — рабочий образец в жанре, который на
Пикабу проходит: личный опыт, признание собственной ошибки, вопрос в конце,
ни одной ссылки.

```json
{
  "community": "ligaenglish",     // ссылка сообщества; без неё — в общую ленту
  "title": "…",                   // до 110 символов
  "text_file": "post.md",         // либо "text": "…"
  "tags": ["Английский язык", "Опыт"],   // минимум 1, максимум 15
  "authors": true,                // тег [моё]
  "adult": false,
  "comments_disabled": false,
  "advert": false,                // рекламный пост (разрешает ссылки)
  "advert_company": ""            // юрлицо; без него рекламный пост не уйдёт
}
```

Разметка текста: пустая строка — новый абзац, `**жирный**`, `*курсив*`,
`[текст](ссылка)`. Картинки инструмент пока не загружает — если пост нужен
с картинками, сделай его в `--dry`, а потом собери руками:
`node driver.mjs open '{"url":"https://pikabu.ru/add"}'`.

## Гарды

Настраиваются в `config.json → guards`, перебиваются флагом `--force`:

| Гард | По умолчанию | Зачем |
|---|---|---|
| `min_hours_between_posts` | 12 | серия постов подряд — подпись бота |
| `max_posts_per_day` | 2 | суточный потолок |
| `days_between_same_community` | 30 | повтор в то же сообщество = спам |
| `comment_to_post_ratio` | 5 | участие против самопиара, считается по своей базе |
| `min_account_rating` | 50 | ниже — пост тонет, не успев показаться |
| `min_account_age_days` | 14 | свежий аккаунт минусуют на автомате |

Вердикт `no` у сообщества («реклама запрещена») закрывает площадку **только для
рекламного поста или поста со ссылкой**. Обычный рассказ туда можно — но без
намёка на своё; инструмент об этом предупредит, а не запретит.

## Грабли (проверено на этой машине 13.08.2026)

- **Читать можно снаружи браузера** — в отличие от Reddit, обычный запрос
  получает 200. Страницы в **windows-1251**, ajax-ответы — в UTF-8 с
  `\u`-экранированием.
- **Действию нужен `X-Csrf-Token`**, и он лежит не в куке, а в теле страницы:
  `<script type="application/json" data-entry="initParams">`. Поэтому действия
  идут изнутри загруженной вкладки — там токен, кукисы и Referer совпадают.
- **`page.goto` с `domcontentloaded` не укладывается в минуту.** На Пикабу
  десяток рекламных сеток, и документ «догружается» бесконечно. Ждать надо не
  загрузку, а появление блока `initParams` (`waitUntil: "commit"` + селектор).
- **`data-timestamp` в лентах сообществ — время отрисовки страницы**, одинаковое
  у всех постов. Настоящая дата — в `<time datetime="…">`. На этом легко
  получить ленту, где всё «0 минут назад».
- **В лентах попадаются рекламные `<article class="story">`** без заголовка
  (`story__placeholder` + adfox). Пост опознаётся только по ссылке на самого
  себя (`…_<story-id>`); иначе в выдачу просачивается чужой заголовок.
- **На собственной странице поста заголовок — не ссылка, а `<span>`**, и
  `canonical` там появляется только при заходе по полному адресу со слагом;
  по короткому `/story/_ID` есть только `og:url`.
- **Комментариев нет в HTML** — они приезжают отдельным запросом
  `POST /ajax/comments_actions.php action=get_story_comments&story_id=N` и
  приходят кусками готового HTML; данные комментария — в `data-meta`
  (`r=` рейтинг, `de=` глубина, `d=` дата).
- **«Нельзя добавить пост со ссылками вне блога»** — этот отказ редактора
  включается только когда Пикабу считает пост рекламным (режим рекламных
  блогов). Обычный пост со ссылками проходит; наказывают за них не отказом, а
  минусами.
- **Новый аккаунт стартует с рейтингом и кармой 100** — это не заработанный
  рейтинг, а аванс, и он не защищает: первые же минусы съедают его быстро.
- **Минусы догоняют быстрее банов.** Удалять заминусованный пост и заливать
  заново нельзя: это читается как обход. Лучше отвечать в комментариях.

## Ручки Пикабу, на которых всё держится

| Что | Запрос |
|---|---|
| Поиск сообществ/тегов/людей | `POST /ajax/search_actions.php` `action=find_tags_users_communities&query=` |
| Сообщества по названию | `GET /ajax/gtpost_actions.php` `action=search_communities&name=` |
| Карточка сообщества | `POST /ajax.php` `route=communities/get-info&id=` |
| Комментарии поста | `POST /ajax/comments_actions.php` `action=get_story_comments&story_id=` |
| Ответить | `POST /ajax/comments_actions.php` `action=create&story_id=&parent_id=&desc=&images=[]` |
| Опубликовать | `POST /ajax/gtpost_actions.php` `action=publish&time=&data=<JSON поста>&story_id=0` |
| Ленты и поиск | обычные страницы: `/hot`, `/new`, `/best`, `/community/<link>`, `/tag/<тег>/hot`, `/search?q=&page=` |
