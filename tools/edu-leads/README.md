# Лиды учебных заведений РФ (ВО и СПО)

База руководства вузов и колледжей России для предложения пилота ESMS —
системы управления электронным расписанием.

```
tools/edu-leads/
  leads.py         — CLI (единственный инструмент)
  edu_leads.db     — база (SQLite, WAL)
  edu_leads.csv    — плоская выгрузка (по команде export-csv)

Органон/08 — Социальный капитал/Учебные заведения РФ/
  MOC — Учебные заведения РФ.md   — сводка, тиры, регионы
  Регионы/{Регион}.md              — учреждения региона и их ЛПР
```

## Откуда берутся данные

**Реестр учреждений с сайтами** — рейтинг сайтов образовательных организаций
VIKON (`db-nica.ru`): отдельно вузы с филиалами и профессиональные
образовательные организации, срез по 90 регионам × 5 лигам. Каждая строка —
название и официальный сайт.

**Контакты** — раздел «Сведения об образовательной организации» на сайте самого
учреждения. По приказу Рособрнадзора № 831 он обязателен, лежит по фиксированному
адресу `/sveden/struct` и размечен микроразметкой: `itemprop="fio"`, `"post"`,
`"email"`, `"telephone"`, `"name"` (подразделение). Поэтому контакты берутся не
догадками из текста, а разбором разметки — и не с агрегаторов, а из первых рук.

Это официально раскрываемые сведения. Для рассылки всё равно смотреть 152-ФЗ и
требования к рекламным сообщениям.

## Тиры

Пишутся **все** найденные люди, ЛПР помечаются тиром:

| Тир | Кто | Зачем |
|---|---|---|
| **A** | ректор, директор, директор филиала, проректор/зам по учебной работе, по цифровизации | подписывает и платит |
| **B** | учебная часть и УМУ, диспетчерская расписания, ИТ-управление, деканы, зав. отделениями | у них болит и они внедряют |
| **C** | все остальные должности со страницы | резерв: через них ищется вход |

Заведомо непрофильное (общежития, столовая, бухгалтерия, охрана, спорт, музей и
т. п.) в A/B не попадает — только в C.

## Команды

```bash
cd "~/Desktop/personal os/tools/edu-leads"

python3 leads.py registry                    # реестр учреждений с сайтами
python3 leads.py crawl --workers 12          # обход /sveden/struct
python3 leads.py crawl --retry               # повтор упавших и пустых
python3 leads.py crawl --region "Краснодар"  # точечно по региону

python3 leads.py stats                       # сводка: тиры, роли, регионы
python3 leads.py show "Кубанский"            # контакты одного учреждения
python3 leads.py export-csv --lpr --with-email
python3 leads.py obsidian                    # заметки по регионам + MOC

python3 leads.py promote --region "Краснодарский край" --tier A --dry
python3 leads.py promote --region "Краснодарский край" --tier A
```

`promote` заводит выбранных людей в [соцкапитал](../social-capital/README.md)
как лидов (`Лиды · Вузы` / `Лиды · Колледжи`) — оттуда `capital.py sync` сделает
карточки в Обсидиане. Массово всех не переносим: 5 000 учреждений × несколько
человек утопят базу людей, поэтому карточка заводится на того, с кем реально
начали разговор.

## Грабли

- **Бюджет времени на учреждение.** Мёртвый сайт с открытым портом держит
  соединение до таймаута по каждому из путей. Отсюда `BUDGET = 70` с и один
  заход на запрос: без него один техникум в Свердловской области занимал поток
  на несколько минут.
- **Битый TLS — норма.** У части сайтов сертификат просрочен или самоподписан,
  поэтому на ошибке TLS идёт повтор с непроверяющим контекстом, а на мёртвом
  `https` — заход по `http`. Обычная сетевая ошибка повтор **не** вызывает,
  иначе обход растягивается втрое.
- **Кодировка.** Немалая часть сайтов до сих пор в `cp1251`; кодировка берётся
  из заголовка, потом из `<meta>`, потом перебором.
- **Не всякий «директор» — ЛПР.** Директор типографии, комбината питания и
  студгородка сидят в той же таблице, что и директор колледжа. Различаются по
  подразделению, а не по должности.
- **Не всякое ФИО — ФИО.** В графе попадаются «Вакансия», «Временно отсутствует»,
  «не назначен» — отсеиваются по форме токенов (учитывая ФАМИЛИИ КАПСОМ и
  инициалы).
