# Research Lab — Agent Team рисёрчеров

Координирую команду исследователей: от выявления требований до научной статьи по ГОСТ, идей, скрытых связей и простого объяснения.

**Agent Team:**
- `research-scout` — выявление требований к рисёрчу (точка входа, спрашивает пользователя)
- `deep-researcher` — глубокий desk research через NotebookLM, анализ источников/книг/заметок
- `pattern-finder` — скрытые связи между знаниями, включая граф Obsidian
- `idea-generator` — генерация идей, гипотез, исследовательских вопросов
- `academic-writer` — научные статьи/рефераты по ГОСТ + критический анализ источников
- `simplifier` — объяснение сложного простым языком через метафоры

**Вспомогательные (Personal OS):**
- `knowledge-agent` — Obsidian: заметки, сохранение артефактов
- `vault-indexer` — обновление семантического индекса перед работой с Obsidian

**Скиллы команды:** `gost-standards` (academic-writer), `notebooklm` (deep-researcher), `obsidian`, `zotero`.

**Режим выполнения:** Agent Team Hybrid (scout → fan-out сбор → fan-in письмо)

**Кросс-командное взаимодействие:**
- Передаёт: научный текст → Office Bureau (`document-writer` для .docx/PDF по ГОСТ, `presentation-designer` для доклада)
- Принимает: запрос на рисёрч от Startup Lab (валидация гипотез) или Psych Team
- Протокол: `.claude/skills/agent-context/references/cross-team.md`

## Phase 1: Выявление требований (research-scout)

**Режим:** одиночный агент, интерактивный.

```
Agent(research-scout, model="opus"): прочитай определение .claude/agents/research-scout.md.
Запрос пользователя: {запрос}. Выяви требования к рисёрчу через AskUserQuestion,
сохрани ТЗ в 10 — Claude/Рабочее пространство/research/00_research_brief.md.
```

Scout задаёт вопросы пользователю напрямую. Дождись ТЗ — без него команда не стартует. Если запрос предельно ясен, scout формирует ТЗ без вопросов.

---

## Phase 2: Параллельный сбор (fan-out)

**Режим:** агент-команда, параллельно (`run_in_background: true`). Все читают `00_research_brief.md`.

| Агент | Задача | Выход |
|-------|--------|-------|
| `deep-researcher` | NotebookLM desk research, анализ источников | `01_research_{тема}.md` |
| `pattern-finder` | скрытые связи (после первичной карты deep-researcher) | `02_patterns_{тема}.md` |
| `idea-generator` | веер идей и гипотез | `03_ideas_{тема}.md` |

Зависимость: `pattern-finder` и `idea-generator` используют карту знаний `deep-researcher` — поэтому deep-researcher стартует первым, остальные подхватывают его `01_*.md` (через TaskCreate-зависимость или последовательный старт). Если ТЗ не требует идей/связей — запускай только нужных.

---

## Phase 3: Синтез и упаковка (fan-in)

**Режим:** агент-команда, по запросу из ТЗ.

- Нужна **научная статья/реферат** → `academic-writer` собирает `01/02/03` в текст по ГОСТ (`04_article_{тема}.md`), читает скилл `gost-standards`.
- Нужно **простое объяснение** → `simplifier` делает популярную версию (`05_explainer_{тема}.md`).
- Нужны только идеи/связи/рисёрч → отдаём артефакты Phase 2 напрямую.

Если нужен финальный **.docx/PDF по ГОСТ или презентация** — передай в Office Bureau (см. кросс-команда).

---

## Phase 4: Сохранение

1. Готовые артефакты → Obsidian через `knowledge-agent` (статьи в раздел знаний, идеи — в раздел идей, связи — отдельными заметками).
2. Сессия команды → `sync-claude-sessions`:
   ```bash
   VAULT="/Users/dimitrisimonyan/Yandex.Disk.localized/Self-Education/Knowledge base/Obsidian/Органон"
   VAULT_DIR="$VAULT" \
   CLAUDE_SESSIONS_OUTPUT="$VAULT/10 — Claude/Контекст и Сессии/Research Lab" \
     python3 ~/.claude/skills/sync-claude-sessions/scripts/claude-sessions export \
     "$(ls -t ~/.claude/projects/-Users-dimitrisimonyan/*.jsonl | head -1)"
   ```

## Обработка ошибок

- NotebookLM недоступен → deep-researcher идёт через WebSearch/WebFetch + Zotero, помечает ограничение.
- vsearch/граф Obsidian недоступны → pattern-finder работает текстовым поиском, отмечает в выводе.
- Агент не завершил → 1 повтор, затем синтез без него с пометкой о пропуске.
- Мало источников → academic-writer переключается на реферативный формат, явно отмечает доказательную базу.

## Тестовые сценарии

**Полный цикл:** «Исследуй тему X и напиши научную статью по ГОСТ» → scout (ТЗ) → deep-researcher + pattern-finder + idea-generator → academic-writer (статья) → Obsidian.

**Частичный:** «Объясни выводы статьи простыми словами» → читается `04_article`, запускается только `simplifier`.

**Ошибка:** NotebookLM офлайн → deep-researcher через web + Zotero, в карте знаний помечено ограничение, остальная команда работает штатно.

## Бюджет контекста

Скилл — диспетчер: раздаёт задания агентам и принимает отчёты. Сам артефакты
агентов не читает и не «проверяет глазами» — проверка это ещё один агент.
Потолки: сессия 55% окна мягкий / 88% жёсткий, субагент 40k / 60k токенов.
Промежуточное — файлом в рабочее пространство команды, в диалог путь и суть.
Фича доведена до конца — чекпоинт и дальше с чистой сессии:

```bash
python3 .claude/hooks/checkpoint.py --note "<что сделано>" --next "<следующий шаг>"
```

Подробности — скилл `context-budget`.
