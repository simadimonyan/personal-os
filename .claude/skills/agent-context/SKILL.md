# Agent Context — Управление контекстом агентов

Позволяет агентам Personal OS читать и сохранять контекст своих сессий в Obsidian. Контекст живёт между сессиями — агент продолжает с того места, на котором остановился.

## Структура в Obsidian

```
10 — Claude/
└── Контекст и Сессии/
    ├── Personal OS/
    │   ├── knowledge-agent.md
    │   └── action-agent.md
    ├── Psych Team/
    │   ├── cognitive-analyst.md
    │   ├── emotional-analyst.md
    │   ├── relational-analyst.md
    │   └── lead-psychologist.md
    └── Startup Lab/
        ├── market-researcher.md
        ├── product-manager.md
        ├── growth-marketer.md
        ├── smm-specialist.md
        └── business-psychologist.md
```

## Формат файла контекста

```markdown
---
type: agent-context
agent: {agent-name}
team: {Personal OS | Psych Team | Startup Lab}
last_sync: YYYY-MM-DD HH:MM
---

# Контекст: {agent-name}

## Последняя активность
**Дата:** YYYY-MM-DD
**Задача:** {над чем работал}

## Ключевые артефакты
- `{path}` — {описание}

## Открытые вопросы
- {вопрос 1}

## Следующие шаги
- {шаг 1}

---

## История синхронизаций

### YYYY-MM-DD HH:MM — {краткое описание этапа}
{что сделал, что нашёл, что произвёл}
```

## Команды Obsidian Driver

Драйвер: `node ~/.claude/skills/obsidian/driver.mjs`

### Прочитать контекст агента

```bash
node ~/.claude/skills/obsidian/driver.mjs obsidian_read '{"name":"{agent-name}"}'
```

Если файл ещё не создан — вернёт ошибку. Обработай это как "первая сессия".

### Создать файл контекста (первый раз)

```bash
node ~/.claude/skills/obsidian/driver.mjs obsidian_create '{
  "title": "{agent-name}",
  "section": "10",
  "subfolder": "Контекст и Сессии/{team}",
  "tags": ["agent-context", "{agent-name}"],
  "content": "---\ntype: agent-context\nagent: {agent-name}\nteam: {team}\nlast_sync: {YYYY-MM-DD HH:MM}\n---\n\n# Контекст: {agent-name}\n\n## Последняя активность\n**Дата:** {date}\n**Задача:** {task}\n\n## Ключевые артефакты\n{artifacts}\n\n## Открытые вопросы\n{questions}\n\n## Следующие шаги\n{next_steps}\n\n---\n\n## История синхронизаций\n\n### {date} {time} — {brief}\n{summary}"
}'
```

### Дописать синхронизацию (файл уже существует)

```bash
node ~/.claude/skills/obsidian/driver.mjs obsidian_append '{
  "name": "{agent-name}",
  "content": "\n### {YYYY-MM-DD HH:MM} — {краткое описание этапа}\n**Задача:** {что делал}\n**Ключевые находки:** {main findings}\n**Артефакты:** {files created or modified}\n**Открытые вопросы:** {unresolved}\n**Следующие шаги:** {next steps}"
}'
```

## Протокол для агентов

### В начале сессии (через оркестратор)

Оркестратор спрашивает пользователя: *«Загрузить контекст предыдущей сессии? (да/нет)»*

- Если **да**: оркестратор читает контекст нужных агентов из Obsidian и передаёт его в prompt при запуске агента.
- Если **нет**: агент начинает чисто, без предыдущего контекста.

Агент, получив контекст, читает:
1. **Открытые вопросы** — что оставалось нерешённым
2. **Следующие шаги** — с чего начать
3. **Ключевые артефакты** — что уже создано и доступно

### Автономная синхронизация (решение агента)

Агент синхронизирует контекст самостоятельно, не дожидаясь конца сессии:

**Триггеры для автосинхронизации:**
- Завершил ключевой этап анализа или исследования
- Создал важный артефакт (файл, отчёт, набор данных)
- Обнаружил неожиданный инсайт, который стоит сохранить
- Принял важное решение о направлении работы

**Шаги синхронизации:**
1. Попробуй `obsidian_read` — если файл есть, используй `obsidian_append`
2. Если файл не найден — используй `obsidian_create` для создания
3. Обнови раздел "Последняя активность" в шапке через `obsidian_append`

### В конце сессии (обязательно)

Всегда синхронизируй финальный контекст:
- Что сделал в этой сессии
- Какие артефакты создал/изменил
- Что осталось нерешённым
- Что делать в следующей сессии

## Для оркестраторов: загрузка контекста нескольких агентов

```bash
# Пример: читаем контекст market-researcher и product-manager
node ~/.claude/skills/obsidian/driver.mjs obsidian_read '{"name":"market-researcher"}'
node ~/.claude/skills/obsidian/driver.mjs obsidian_read '{"name":"product-manager"}'
```

Каждый найденный контекст включается в prompt соответствующего агента:

```
Контекст предыдущей сессии для тебя:
{содержимое файла контекста}
---
Твоя задача в этой сессии: {task}
```
