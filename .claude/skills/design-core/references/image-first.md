# Конвейер «сначала картинка, потом код»

Источники: `imagegen-frontend-web`, `imagegen-frontend-mobile`,
`image-to-code`, `brandkit`.

Отдельный режим работы: когда задача в первую очередь про **вид**, дизайн
сначала рисуется картинками, и только потом верстается. Так проще выбросить
неудачное направление: выбросить картинку дешевле, чем переписанный компонент.

---

## 1. Когда включать этот режим

Включать, если просьба звучит про внешний вид: красивый первый экран,
премиальный лендинг, редизайн, «сделай современнее», портфолио, витрина
стартапа, многосекционная концепция сайта.

Не включать, когда задача техническая: починить баг, собрать по уже готовой
дизайн-системе, изменить структуру без изменения вида. Тогда прямо в код.

## 2. Порядок

1. Определить количество секций.
2. Сгенерировать **референсные картинки по секциям**.
3. Догенерировать детальные виды там, где нужно (крупный план компонента).
4. Непонятные секции — **перегенерировать заново целиком**.
5. Разобрать все картинки внимательно.
6. Вынуть текст, типографику, отступы, цвета, раскладку, кнопки, логику
   компонентов.
7. Сверстать максимально близко к картинкам.
8. Домысливать только там, где картинка оставила неоднозначность.

Картинки — источник арт-дирекшна. Код — слой реализации.

## 3. Главное правило: одна секция — одна горизонтальная картинка

Всегда. Никогда не склеивать несколько секций в один кадр, не отдавать одну
высокую полосу со всей страницей, не отдавать одну «лучшую» картинку вместо
набора.

Если число секций не задано, брать по верхней границе:

| Просьба | Секций |
|---|---|
| первый экран | 1 |
| лендинг, шаблон сайта | 6 |
| продуктовая страница | 6 |
| портфолио | 6 |
| полный сайт, маркетинговый сайт | 8 |

Формат: горизонталь всегда (16:9, 16:10, 21:9 по плотности). Первый экран
обычно 16:9 или 21:9.

Если за раз рисуется одна картинка — рисовать подряд в одном ответе, подписывая
«Секция X из N: название», пока набор не полон.

## 4. Ритм и единство

**Разная амбиция секций** — часть работы: несколько крупных
арт-директированных, несколько средних редакционных, несколько совсем тихих,
почти из одного воздуха. Одинаковые по плотности плиты подряд читаются дёшево.

**Единый мир** через весь набор: одна палитра и логика акцента, одна гарнитура
и шкала, одно семейство кнопок, один язык радиусов, одна обработка изображений,
один тон коротких текстов. Человек, пролистывающий кадры, должен видеть один
сайт, а не подборку.

## 5. Не резать старое, а генерировать новое

- Кроп предыдущей картинки вместо новой генерации запрещён: обрезок теряет
  разрешение и композицию.
- Нужен крупный план компонента — отдельная свежая картинка.
- Секция вышла неудачно — перегенерировать её целиком, а не латать.
- Мелкие сжатые «доски» из многих секций в одном кадре не годятся: по ним
  нельзя верстать, там не читается ни кегль, ни отступ.

## 6. Извлечение из картинки в код

По каждой картинке снимается и записывается **до** первой строки вёрстки:

| Что | Как снимать |
|---|---|
| Текст | дословно, включая подписи кнопок и микрокопирайт |
| Типографика | классификация гарнитуры, соотношения кеглей, вес, интерлиньяж, трекинг |
| Отступы | в единицах шкалы (кратность 4/8), а не «на глаз» |
| Цвет | палитра значениями, роли; сразу в токены |
| Кнопки и компоненты | форма, радиус, заливка, граница, размер, состояния |
| Раскладка | сетка, колонки, точки перелома |

Затем — защита от расползания: сверстанное сравнивается с исходной картинкой
покадрово. Расхождение либо чинится, либо объявляется осознанным решением с
причиной. Молчаливый дрейф от референса — самая частая потеря качества в этом
режиме.

## 7. Чего не делать в первом экране

- Никаких вложенных коробок в коробках в коробках.
- Никакого мелкого интерфейсного мусора: бейджи, пилюли, счётчики, версии.
- Заголовок 2–3 строки, не больше.
- Первый экран остаётся чистым, просторным и читаемым на маленьком ноутбуке.

## 8. Бренд-борды (brandkit)

Отдельный жанр: не интерфейс, а система идентичности.

**Сначала стратегия, потом картинка.** До генерации формулируются: суть бренда
одной фразой, характер, для кого, чем не является.

Методы концепции логотипа: монограмма со смыслом · действие продукта ·
слияние метафор · негативное пространство · геометрия построения.

Стандартная доска — сетка 3×3: обложка с логотипом · построение логотипа ·
цифровое применение · суть бренда · цветовая система · типографика ·
физическое применение · направление съёмки · деталь системы.

Через все панели держится один мир: палитра, гарнитура, обработка,
материальность.

`10 — Claude/Рабочее пространство/dev/ui/refs/{проект}/`.

визуальных референсов:
`09 — Шаблоны и ресурсы/Визуальные референсы/` (движок — `tools/context-store/store.py`),
чтобы следующая задача начиналась не с нуля.
