# Протокол бюджета контекста — детали

Основано на context-engineering-kit (NeoLabHQ), плагины `sadd` и `sdd`,
перенесено на Personal OS.

## Что взято из источника

| Принцип источника | Как лёг в Personal OS |
|-------------------|------------------------|
| Fresh subagent per task — свежий агент на задачу, без загрязнения контекста | Команды и так работают через субагентов; добавлены потолки 40k/60k и учёт расхода |
| «You are an ORCHESTRATOR ONLY» — оркестратор не читает артефакты | Правило 1 в SKILL.md, врезка в командные скиллы |
| Состояние живёт в файлах, а не в контексте (`todo/in-progress/done`, метки `[DONE]`) | Чекпоинт + журнал фич + существующая L-память в Obsidian |
| `--continue`: восстановление состояния из файлов | `session_start_status.py` подмешивает чекпоинт в новую сессию |
| Скретчпад для длинных выкладок | Рабочее пространство команды в Obsidian |
| Команды дешевле скиллов: описание скилла грузится всегда | Описания агентов и скиллов держим короткими; справочники — в `references/` |
| «Pay a token budget inside the change's scope» — не резать то, чего не просили | Разгрузка `CLAUDE.md` сделана переносом, а не удалением: журнал целиком лежит в `docs/harness-changelog.md` |
| Quality gate между задачами | Уже есть: code-reviewer / design-reviewer / tech-lead в Dev Lab |

Осознанно не взято: FPF с уровнями L0/L1/L2 и trust-калькуляцией (в системе
уже своя L-память L0→L4, две конкурирующие нумерации путали бы), собственный
`.specs/`-конвейер задач (дублирует рабочее пространство в Obsidian),
LLM-as-judge поверх каждой мелочи (дорого на каждую правку).

## Ступени сторожа

`context_guard.py` висит на `Stop` — раз в ход, не на каждый инструмент.
Доли считаются от `autoCompactWindow` (140k):

- **55%** — `systemMessage` пользователю, тихо. Смысл: следующую крупную
  задачу начинать с чистой сессии.
- **75%** — `additionalContext` агенту: доводи текущее, не начинай новое.
- **88%** — `decision: block` один раз за сессию: ход не заканчивается,
  пока не записан чекпоинт. Флаг `stop_hook_active` защищает от петли,
  флаг `forced` в состоянии сессии — от повтора.

Состояние сессии — `.claude/state/session-<id>.json`, чтобы одно и то же
предупреждение не повторялось каждый ход.

## Формат чекпоинта

Смысловую часть даёт агент (`--note`, `--next`), механическую собирает
скрипт: ветка, `git diff --stat`, незакоммиченные файлы, последние коммиты,
файлы, правленые в сессии (вынимаются из транскрипта по вызовам Write/Edit).

Держится 6 последних блоков; в старт новой сессии подмешивается верхний,
обрезанный до 2600 символов, плюс 5 последних строк журнала фич.

## Измерение

Реальный размер контекста берётся из транскрипта сессии — поле `usage`
последнего ответа: `input_tokens + cache_read_input_tokens +
cache_creation_input_tokens`. Это точное число, а не оценка по символам.

Замер расхода по всем сессиям:

```bash
python3 - <<'PY'
import json, glob, os
for p in sorted(glob.glob(os.path.expanduser(
        '~/.claude/projects/-Users-dimitrisimonyan-Desktop-personal-os/*.jsonl')),
        key=os.path.getmtime)[-10:]:
    mx = 0
    for line in open(p, errors='ignore'):
        try: d = json.loads(line)
        except Exception: continue
        u = (d.get('message') or {}).get('usage')
        if u: mx = max(mx, u.get('input_tokens',0) + u.get('cache_read_input_tokens',0)
                           + u.get('cache_creation_input_tokens',0))
    print(f'{mx:>8}  {os.path.basename(p)[:8]}')
PY
```
