# Шаблоны учебных материалов

Читай при создании конкретных артефактов. Заполняй под тему и уровень ученика.

## Глаголы целей по Блуму (для формулировки целей обучения)

| Уровень | Глаголы |
|---------|---------|
| Запоминание | назвать, перечислить, дать определение, воспроизвести |
| Понимание | объяснить, описать своими словами, привести пример, классифицировать |
| Применение | решить, применить, реализовать, вычислить, использовать |
| Анализ | сравнить, разложить на части, выявить причину, найти ошибку |
| Оценка | обосновать, выбрать с аргументацией, оценить, критиковать |
| Создание | спроектировать, построить, разработать, собрать воедино |

Формула цели: «По итогам [модуля] ученик сможет [глагол] [объект] [условие/критерий]».

## Карта курса (curriculum-architect → 01_curriculum.md)

```markdown
# Программа: {тема}
**Уровень:** ... · **Цель:** ... · **Срок:** ... ({часов/нед})

## Целевые результаты (что уметь в конце)
1. [глагол Блума] ...
2. ...

## Модули
### M1. {Название}
- Цель модуля: [уметь ...]
- Предпосылки: [что знать до]
- Темы: ...
- Время: ~N ч
### M2. ...

## Последовательность и зависимости
M1 → M2 (M2 требует ... из M1) → ...

## Контрольные точки
- После M2 — рубежный квиз
- После M4 — milestone-проект

## Карта результатов
| Модуль | Что уметь | Как проверим |
|--------|-----------|--------------|
| M1 | ... | квиз M1 |
```

## Лекция (lecturer → lectures/M{N}_{тема}.md)

```markdown
# M{N}. {Тема}
**Цель:** к концу — [уметь ...]

## Зачем это (мотивация)
{где применяется, какую проблему решает}

## Опора на известное
{связь с предыдущим}

## Ядро
### Концепт 1
{определение → объяснение «почему» → }
**Пример (worked):** {пошаговый разбор с рассуждением}
### Концепт 2 ...

## Типичные заблуждения
- {что понимают неправильно и почему на самом деле}

## Проверь себя (активное припоминание)
1. {вопрос} 2. {вопрос}

## Конспект (для повторения)
- {ключевое в 3-5 пунктах}
```

## Задания (exercise-designer → exercises/M{N}_exercises.md)

```markdown
# Задания M{N}

## Разминка (распознавание)
1. {условие} · _проверяет:_ {цель} · _ответ:_ {в конце}

## Основные (применение)
2. {условие} · _критерий успеха:_ ... · _подсказки:_ 1)... 2)... · _решение:_ {отдельно}

## Со звёздочкой (перенос/анализ)
3. ...

## Проект (на milestone)
{комплексное задание + рубрика}

---
## Решения
{ответы и разборы — отдельным блоком, чтобы скрыть при самопроверке}
```

## Проверка (assessment-designer → assessments/M{N}_quiz.md)

```markdown
# Квиз M{N}
> Формирующий: цель — диагностика, не стресс.

1. [Понимание] {вопрос с выбором}
   - а) ... б) ... в) ...
   _Ответ:_ б. _Разбор:_ {почему б, почему а и в — типичные ошибки}
2. [Применение] {задача}
   _Ответ:_ ... _Разбор:_ ...

## Критерий освоения
{сколько верных = готов идти дальше; что повторить при пробелах}
```

## Рубрика (для открытых заданий/проектов)

```markdown
| Критерий | Отлично | Хорошо | Нужно доработать |
|----------|---------|--------|------------------|
| {аспект 1} | ... | ... | ... |
| {аспект 2} | ... | ... | ... |
Освоено = все критерии не ниже «Хорошо».
```

## Учебный план (learning-coach → PLAN.md)

```markdown
# План обучения: {тема}
**Темп:** {N ч/нед} · **Срок:** ~{недель}

## Неделя 1
- [ ] Занятие 1: лекция M1 → задачи M1 (1-5) → квиз M1
- [ ] Занятие 2: ...
## Неделя 2
- [ ] ...
- [ ] 🔁 Повторение: вернуться к M1 (активное припоминание)

## График повторений (интервальный)
- M1: через 2 дня, через неделю, через 3 недели
- На повторениях чередовать темы (interleaving)

## Milestone'ы
- После M2: рубежный квиз — порог {X}%
- После M4: проект

## Прогресс
- [x] M1 освоен ({дата})
- [ ] M2 в работе
```
