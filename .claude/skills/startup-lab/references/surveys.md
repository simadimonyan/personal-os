# Опросы на Яндекс Формах

Стартап-команда умеет собирать не только кабинетные данные, но и живые ответы:
опрос собирается из JSON-спеки и выкладывается в Яндекс Формы одной командой.

Инструмент: `tools/yandex-forms/yaapi.mjs` (описание внутренностей — `tools/yandex-forms/README.md`).

---

## 1. Кому и зачем

| Агент | Типичный опрос |
|-------|----------------|
| `market-researcher` | валидация гипотезы, скрининг перед кастдевом, размер и боли сегмента |
| `product-manager` | обратная связь по продукту, приоритизация фич, NPS после релиза |
| `growth-marketer` | ICP, проверка формулировок ценности, каналы и триггеры покупки |
| `smm-specialist` | опрос подписчиков канала: темы, формат, что мешает |
| `hr-specialist` | скрининг кандидатов, опрос о культуре и вовлечённости |

Опрос — не замена кабинетному рисёрчу и NotebookLM, а способ проверить то, чего в
источниках нет: как думает конкретная аудитория Димитри.

---

## 2. Как это делается

```bash
cd "<репозиторий>/tools/yandex-forms"

node yaapi.mjs check  <путь к спеке>              # проверить, ничего не создавая
node yaapi.mjs build  <путь к спеке>              # собрать черновик
node yaapi.mjs build  <путь к спеке> --publish    # собрать и опубликовать
node yaapi.mjs list                               # формы аккаунта
node yaapi.mjs delete <surveyId>                  # удалить

node yaapi.mjs insert <surveyId> <спека> --section 1 --take 2   # дописать вопросы в живую форму
```

**Форму, которую уже разослали, не пересобирают.** `build` создаёт новую форму с новым
`surveyId` — старая ссылка перестаёт вести на актуальный опрос, а собранные ответы остаются
в прежней форме. Правки в уже разосланную форму вносятся так: сначала та же правка в спеке,
затем `insert` (по умолчанию кладёт вопросы в начало первой страницы, остальные сдвигает вниз;
`--page`/`--position` — если нужно в другое место). В ответе `headAfter` — начало страницы
после вставки, по нему сверяется порядок.

Спеку агент кладёт в рабочее пространство своей команды, а не в общий `forms.json`:

```
10 — Claude/Рабочее пространство/startup/research/surveys/{имя}.json
```

`build` принимает: путь к своему файлу, `путь.json#ключ` (если в файле несколько форм)
или ключ из общего `tools/yandex-forms/forms.json`.

Результат — `surveyId`, ссылка на редактирование и (при `--publish`) ссылка на
заполнение `https://forms.yandex.ru/u/<surveyId>/`. Обе ссылки сразу записать в отчёт
команды и передать пользователю.

## 3. Формат спеки

```jsonc
{
  "title": "Название опроса",
  "description": "Одно предложение: зачем это респонденту и сколько займёт",
  "sections": [                       // раздел = отдельная страница формы
    {
      "title": "О себе",
      "questions": [
        { "type": "radio", "required": true, "title": "Как часто вы…?",
          "options": ["Каждый день", "Раз в неделю", "Реже", "Никогда"] },
        { "type": "textarea", "title": "Что было сложнее всего?",
          "description": "Своими словами, 1–2 предложения" }
      ]
    }
  ]
}
```

Типы вопросов: `text` · `textarea` · `number` · `email` · `phone` · `link` ·
`radio` · `checkbox` · `select` · `boolean` · `date` · `scale`
(у `scale` — `rows[]` и `columns[]`, по умолчанию 1–5).

## 4. Правила хорошего опроса (соблюдать, не выдумывать заново)

1. **Спрашивать о прошлом поведении, а не о будущих намерениях.** «Сколько вы
   потратили на это за последние 3 месяца?» вместо «Готовы ли вы платить?» —
   второе даёт вежливое «да» и нулевую предсказательную силу.
2. **Один вопрос — одна мысль.** «Удобно и быстро ли?» разваливается на два.
3. **Не подсказывать ответ формулировкой.** «Насколько вас раздражает…» уже
   назначило респонденту эмоцию.
4. **Скрининг — первым разделом.** Отсечь не-целевых до основных вопросов, иначе
   выборка размоется.
5. **Открытый вопрос в конце каждого блока** — там живёт язык аудитории, который
   потом идёт в позиционирование дословно.
6. **Длина.** До 12 вопросов на короткий опрос, до 30 — на глубокий; больше пятнадцати
   минут не заполняет почти никто. Заявленное время писать в `description` честно.
7. **`required` — только там, где без ответа анкета бессмысленна.** Обязательные
   открытые вопросы роняют долю завершений сильнее всего.
8. **Демография — в конце**, кроме скрининга: в начале она отпугивает.
9. Перед сборкой показать пользователю список вопросов и получить «да» — форма
   уходит живым людям от его имени.

## 5. Грабли

- Публичного API на создание форм у Яндекса нет — работаем через внутренний API
  конструктора залогиненным браузером. Если сессия отвалилась: `node yaforms.mjs login`
  (интерактивно, пользователь входит сам).
- Сборка идёт по одному вопросу — 39 вопросов это ~1–2 минуты, это нормально.
- Черновик виден только владельцу: без `--publish` ссылку на заполнение не отдавать.
- Ответы забираются в кабинете Форм; автоматической выгрузки ответов в базу пока нет
  (публичный API ответов есть только у Форм для бизнеса).
- Ссылку на форму рассылать по Telegram-чатам — только через правила фермы аккаунтов
  (`~/.claude/skills/telegram/references/account-farm.md`): рассылочный аккаунт, паузы,
  дневной потолок.
