# Библиографические описания по ГОСТ — примеры

Читай при составлении «Списка использованных источников». Соблюдай единообразие: все записи в одном стиле, знаки препинания (`. —`, `:`, `/`, `//`) строго по образцу.

## ГОСТ Р 7.0.100-2018 — основной актуальный стандарт

### Книга, один автор
```
Фамилия, И. О. Заглавие книги : сведения, относящиеся к заглавию / И. О. Фамилия. — Город : Издательство, год. — Кол-во с.
```
Пример:
```
Иванов, А. С. Теория систем : учебник / А. С. Иванов. — Москва : Наука, 2020. — 320 с.
```

### Книга, два-три автора
```
Петров, И. И. Основы анализа данных / И. И. Петров, С. С. Сидоров. — Санкт-Петербург : Питер, 2021. — 256 с.
```

### Книга, четыре и более авторов
```
Заглавие книги / И. И. Петров, С. С. Сидоров, А. А. Козлов, В. В. Новиков. — Москва : Юрайт, 2022. — 400 с.
```

### Статья из журнала
```
Фамилия, И. О. Заглавие статьи / И. О. Фамилия // Название журнала. — год. — Т. X, № Y. — С. NN–MM.
```
Пример:
```
Смирнов, П. А. Когнитивные искажения в принятии решений / П. А. Смирнов // Вопросы психологии. — 2019. — Т. 12, № 3. — С. 45–58.
```

### Статья из сборника
```
Фамилия, И. О. Заглавие статьи / И. О. Фамилия // Название сборника : материалы конференции. — Город : Издательство, год. — С. NN–MM.
```

### Электронный ресурс
```
Фамилия, И. О. Заглавие / И. О. Фамилия. — Текст : электронный // Название сайта : [сайт]. — URL: https://... (дата обращения: 08.10.2026).
```
Пример:
```
Кузнецов, Д. В. Методы машинного обучения / Д. В. Кузнецов. — Текст : электронный // Хабр : [сайт]. — URL: https://habr.com/ru/post/123456 (дата обращения: 08.10.2026).
```

### Диссертация / автореферат
```
Фамилия, И. О. Заглавие : специальность XX.XX.XX «Название» : диссертация на соискание учёной степени кандидата наук / И. О. Фамилия. — Город, год. — Кол-во с.
```

### Нормативный акт / закон
```
Об образовании в Российской Федерации : Федеральный закон от 29.12.2012 № 273-ФЗ. — Текст : электронный // КонсультантПлюс : [сайт]. — URL: ... (дата обращения: ...).
```

### ГОСТ
```
ГОСТ Р 7.0.100—2018. Библиографическая запись. Библиографическое описание. Общие требования и правила составления : национальный стандарт Российской Федерации. — Москва : Стандартинформ, 2018. — 65 с.
```

## ГОСТ Р 7.0.5-2008 — затекстовые ссылки в тексте

- Ссылка на источник: `[10]`
- Ссылка со страницей: `[10, с. 81]`
- Несколько источников: `[10; 15; 23]`
- Диапазон страниц: `[10, с. 81–84]`

## Правила оформления списка

1. Заголовок: «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ» (или «Список литературы»).
2. Нумерация сквозная арабскими цифрами.
3. Порядок (выбрать один и держать весь список):
   - **по алфавиту** фамилий авторов / заглавий (самый частый для статей);
   - **по порядку упоминания** в тексте (под номер ссылки `[N]`);
   - **по группам**: нормативные акты → книги и статьи (по алфавиту) → электронные ресурсы → источники на иностранных языках.
4. Между областями описания — `. —` (точка, пробел, тире, пробел).
5. Единообразие: если у одной книги указано число страниц `— 320 с.`, указывай у всех монографий.

## Частые ошибки (избегать)

- Разнобой: где-то «М.», где-то «Москва» — выбери одно (актуально: полное название города).
- Пропуск даты обращения у электронных ресурсов.
- Отсутствие диапазона страниц у статей `С. 45–58`.
- Неверный знак между автором и заглавием — после фамилии запятая и инициалы: `Иванов, А. С.`
- Смешение стилей 7.1-2003 и 7.0.100-2018 в одном списке.
