# Шаблоны структуры документов

Скелеты для `document-writer` и `academic-writer`. Заполняй данными, плейсхолдеры `[___]` оставляй где данных нет.

## Научная статья
```
УДК [___]
ЗАГЛАВИЕ СТАТЬИ
И. О. Фамилия (организация, город)

Аннотация: [150–250 слов: проблема, цель, методы, результат]
Ключевые слова: [5–7 через запятую]

Введение [актуальность, проблема, цель, задачи, объект, предмет]
1. [Раздел — теория/обзор]
2. [Раздел — анализ/методы]
3. [Раздел — результаты/обсуждение]
Заключение [выводы по задачам, новизна, перспективы]
Список использованных источников [по ГОСТ Р 7.0.100-2018]
```

## Отчёт (ГОСТ 7.32-2017)
```
Титульный лист
Реферат [объект, цель, методы, результаты, объём, кол-во источников/рисунков/таблиц]
Содержание
Введение
1 Основная часть (разделы 1, 1.1, ...)
2 ...
Заключение
Список использованных источников
Приложения (А, Б, В)
```

## Договор
```
ДОГОВОР № [___]
г. [___]                                        «__» ________ 20__ г.

[Сторона 1], именуемое в дальнейшем «[___]», в лице [должность, ФИО],
действующего на основании [___], с одной стороны, и
[Сторона 2], именуемое «[___]», в лице [___], с другой стороны,
заключили настоящий договор о нижеследующем:

1. Предмет договора
2. Права и обязанности сторон
3. Цена договора и порядок расчётов
4. Ответственность сторон
5. Форс-мажор
6. Срок действия и порядок расторжения
7. Прочие условия
8. Реквизиты и подписи сторон

[Реквизиты Стороны 1]        [Реквизиты Стороны 2]
________ / [ФИО]             ________ / [ФИО]
        М.П.                         М.П.
```
